# Wareboxes

Wareboxes is a warehouse management platform for facility operators and multi-client 3PLs. Development covers receiving, inventory control, fulfillment, reporting, and integrations, with a .NET 10 backend, an Angular operations console, and a native Android scanner application.

Wareboxes is currently **pre-production**. Production readiness is tracked through explicit release, performance, security, and operational acceptance gates.

The [private development repository](https://github.com/wareboxes/wareboxes) contains the source code, setup instructions, architecture, and product roadmap. Current issues and pull requests are tracked in the [Wareboxes Development project](https://github.com/orgs/wareboxes/projects/3).
